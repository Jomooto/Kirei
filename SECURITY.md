# Security Policy

## Supported Versions

Only the latest released version of Kirei is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.2.x  | :white_check_mark: |
| < v0.2  | :x:                |

## Reporting a Vulnerability

Security is a fundamental priority for Kirei, particularly because the application interacts with system cleanup tasks and elevates privileges using Apple's Touch ID / `osascript`.

If you discover a security vulnerability within Kirei:
1. **Do not create a public issue.**
2. Send an email to [contact/maintainer] or report a private security advisory through GitHub:
   - Go to the **Security** tab of this repository.
   - Click **Report a vulnerability**.
3. Please include detailed steps to reproduce the issue and the potential impact.

We will acknowledge receipt within 48 hours and work on a fix promptly.
